# Changelog

## v0.1.0 — 2026-09-09

- Native SwiftUI grid, customizable workspace regions and unified macOS window.
- Stable space identities with insertion, movement, removal, resizing and proportion APIs.
- Continuous divider/intersection dragging with grid snapping on release.
- Animated insertion, maximize, minimize and banner restoration.
- Per-panel colors, content, header actions, overlays and replacement builders.
- Custom window brand, up to three adjacent action/link buttons and collapsible layout controls.
- Optional footer with independent leading and trailing SwiftUI content slots.
- MIT license, Swift Testing coverage, strict SwiftLint/swift-format checks and GitHub Actions CI.
- Chinese and English documentation, compiled SDK examples and release version consistency checks.
